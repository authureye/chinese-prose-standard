# 标准汉语（语序与书面规范）

> 用途：写文档、说明、报告、代码注释、索引时对照。
> 对话口语不必逐句套；但语序错到读不懂、长句读不断气的，按这里改。
> 本文件是权威资料的**可执行摘要**，不是替代品。要查原文看第十一节。
> 配套的《AI 腔与套话拦截》在同目录的 `ai-tone-blacklist.md`，管的是腔调，这份管的是语序。

---

## 零、写句七条（动笔时只记这七条）

1. **一句一个主语。** 主语换了就断句，新句子开头把主语写出来，不用「他/这/其」硬接。
2. **一句一个动作。** 第二个动作另起一句，不靠逗号一路连下去。
3. **并列项同类。** 名词配名词，小句配小句。同一个列表里一半是「借火岩」一半是「为什么闭阁」，读的人要重新换挡。
4. **修饰语贴中心语。** 中间不插别的成分。「十岁的李清凝父母早逝」会读成「她父母」；该写成「李清凝父母早逝，十岁那年被救走」。
5. **句末不挂新信息。** 结尾那半句是重点位置，不放没交代过的人和事。「玄离也在其中」挂在一个动作串末尾，读者不知道「其中」指哪儿。
6. **一个观点一句陈述句。** 主谓齐全，读完不用等下一句。限定条件进句子，不放句尾；重点在主语或谓语，不在逗号后面。
7. **删后半句验一遍。** 把逗号后面那半删掉，前句还站得住，才算写完了；站不住说明一个判断被拆成了两句。

汇报和警告另按第十三节，格式短，先看那一节。
这七条是**写的时候**用的。下面十二节是**查的时候**用的，篇幅长，只在改稿时翻。

## 一、三条总原则

1. **已知在前，新信息在后。** 先给对方已经知道的人或物当话题，再说新情况。汉语没有格变化，靠位置分工：句首是话题，句末是重点。
2. **修饰语靠近被修饰的成分。** 关系越密切，离得越近。修饰语和中心语之间插进别的东西，读的人就要回头找。
3. **事理顺序就是语序。** 先发生的先说，原因在结果前，条件在结论前，动作在目的前。戴浩一把这条叫「时间顺序原则」，是汉语语序最硬的一条规律。

## 二、定语顺序（多个「的」怎么排）

**口诀：谁的 → 哪儿/何时 → 这那几 → 干什么的 → 什么样的 → 什么料**

例（正确）：

> 国家队的｜一位｜有二十多年执教经验的｜优秀的｜篮球｜教练

错例与病因：

| 错 | 病因 |
| --- | --- |
| 一位优秀的有二十多年执教经验的国家队的篮球教练 | 领属跑到最后，读者以为是「国家队的教练」被一堆形容词修饰 |
| 漂亮的姐姐的那条长裙 | 描写性定语压住领属性定语，关系颠倒 |
| 高大的那所校园里的树木 | 同上，性状在前、处所在后 |
| 两千年前刚修复的铜器 | 「刚修复」和「两千年前」抢同一个位置，读成两千年前修的 |

细则：

- 带「的」的定语放前面，不带「的」的（质料、属性：羊皮、塑料、木质）紧贴中心语。
- 数量词必须贴着它统计的名词。「两个学院的老师」= 两所学院还是两个老师，说不清；改成「学院的两名教师」。
- 一句话两个以上「的」，先怀疑自己排错了。

---

## 三、状语顺序（动作前面那一串）

**顺序：目的/原因 → 时间 → 处所 → 范围/频率 → 情态 → 对象**

例（正确）：

> 许多老师｜昨天｜在休息室里｜都｜热情地｜同他｜交谈

- 目的、原因常在句首，用逗号隔开：「为了赶在封路前到，他一早出发。」
- 表示对象的介宾短语紧贴动词。上例写成「都同他热情地交谈」也通行，两种都算对，只是语义重心不同；但不能把对象甩到句子另一头。
- 时间状语常可提到主语前，处所一般不行。
- 「在」字结构位置决定意思：「他在厨房里做饭」是地点，「他掉在水里」是结果位置。语序一换，意思变。

## 四、虚词位置（最容易错的一类）

**关联词：两个分句主语相同 → 在主语后；主语不同 → 在主语前。**

| 错 | 对 | 原因 |
| --- | --- | --- |
| 小李因为睡眠不好，所以父母很为他担心 | 因为小李睡眠不好，所以父母很为他担心 | 前句主语「小李」、后句「父母」，不同，关联词提到主语前 |
| 同学们很敬佩王老师，因为不仅她课讲得好，而且品德高尚 | 因为她不仅课讲得好，而且品德高尚 | 两个分句主语都是「她」，相同，关联词在主语后 |
| 他如果不能实事求是，事业就会受到损失 | 如果他不能实事求是，事业就会受到损失 | 主语不同，提到句首 |

**否定词：放在「把 / 被 / 将」前面。**

- 错：美国把世界不放在眼里 → 对：美国不把世界放在眼里
- 错：我们把这本书不认真读好 → 对：我们不把这本书认真读好

**介词短语紧贴动词，别把它和动词隔开。**

- 错：把动物用绳子缚在架子上 → 对：用绳子把动物缚在架子上

**主客不能颠倒。**

- 错：张艺谋的《十面埋伏》对于中国青年是不陌生的 → 对：中国青年对《十面埋伏》并不陌生
- 错：本市蔬菜的供应，居民反映经常缺货 → 对：居民反映本市蔬菜经常缺货

## 五、并列与分句的顺序

并列项按 **时间先后 / 空间远近 / 程度轻重 / 范围大小 / 因果** 排，不能随手颠倒。

| 错 | 对 | 依据 |
| --- | --- | --- |
| 讨论、听取厂长报告 | 听取、讨论厂长报告 | 先听后议 |
| 接受、理解和掌握 | 理解、接受和掌握 | 先懂，再受，再掌握 |
| 催人进取、促人猛醒、引人深思 | 引人深思、促人猛醒、催人进取 | 由浅入深 |
| 学生、领导和老师 | 领导、老师和学生 | 由尊及卑，公文惯例 |

动词连用按发生顺序：

- 张三上床睡觉（不是「睡觉上床」）
- 我们开会解决问题（不是「解决问题开会」）
- 他念完了这本书（动作—结果，不能倒）

分句之间：原因→结果、条件→结论、让步→转折、先说共同点再说分歧。

## 六、长句怎么切（竹节，不是树）

英语句子是树：一个主干，枝上再长枝。汉语句子是竹节：一节一节往下走，节与节用逗号连。

三条硬规则：

1. **一句一个动作。** 超过两个动作就考虑断句。
2. **前置修饰最多两层。** 第三层必须搬出去变成后置小句。
3. **读到要换气的地方，就是该断的地方。**

| 错（超长定语） | 对（拆开） |
| --- | --- |
| 这款刚刚落地的主打城市通勤的低成本国产自动驾驶系统 | 这款国产自动驾驶系统成本低，主打城市通勤，刚刚落地 |
| 他被委派了明天上午陪伴那位新来的医生去病房巡视一周的轻松的任务 | 他接到一个任务：明天上午陪新来的医生查房，走一圈就行 |
| 人口现正接近五百万的本市，存在着生存空间日趋狭窄的问题 | 本市人口接近五百万，生存空间越来越窄 |

## 七、重点不后置（一个观点一句陈述句）

**一句一体：一个判断只用一句说清，读者不必往下找补。**

三种形态，都表现为重点落在逗号后面：

1. **半句悬空。** 前半句只给半截信息，后半句补限定，读者按前半句先理解了一遍。
2. **主句空转。** 前半句只是话题或引子，真正的判断在后半句。
3. **补充代断言。** 句尾追加「其实 / 主要是 / 严格说 / 至少现在看」这类，把该进主句的内容挤到末尾。

成因一句话：边写边想，先把顺口的词当话题抛出去占位，落笔后才发现要说的是后半句，于是拿逗号补。纸面上就成了重点倒置。

| 错 | 对 | 病因 |
| --- | --- | --- |
| 这个方案能用，但只在规模不大的时候 | 这个方案只在规模不大时能用 | 限定挂句尾 |
| 成本是个问题，尤其在小场景 | 小场景下成本成问题 | 话题占了主语位置 |
| 语序有问题，我说的是句子内部的 | 句子内部的语序有问题 | 半句悬空 |
| 那伽很强，强到老君打不过 | 那伽强到老君打不过 | 前半句重复一遍再升级 |
| 文档我改过了，主要是语序 | 我把文档的语序改了一遍 | 重点藏在补充里 |
| 他走的时候把门带上了，很小心 | 他走时小心地带上了门 | 状语被甩出句外 |
| 这不是现在的问题，是长期的问题 | 这是长期的问题，眼下不急 | 否定—改正结构，两半都要读才懂 |

细则：

- 限定条件要么进主句，要么整句提到前面。条件在前、结论在后，同在一句。
- 补充句只添新事实，不补前一句没说完的意思。
- 一句只下一个判断。两个判断各给一句。
- 破折号、括号、追问式收尾，一段里最多一处。多了解释等于没下断言。
- 不用冒号把主干推到后面。「结局落在两件事上：A，B」写成「A。B。」冒号后该接并列清单，不接唯一的答案。
- 总结类回答写到事实为止，评价最多一句。「真正的推动力是……」「整部作品的底色是……」这类段，用户没问就不写。
- 动词要配得上宾语，不让读者补成分。先换动词，「牌认了她」换成「她被牌认可」就齐了；改被动次之，加补语最后。「认」在承认身份这个义项上要带「作 / 当 / 为」，只跟人会被读成「认出」。

## 八、翻译腔与欧化（语序乱的常见源头）

| 症状 | 错 | 对 |
| --- | --- | --- |
| 弱动词 | 作出让步 / 进行讨论 / 得到提升 | 让步 / 讨论 / 提升 |
| 「的存在」 | 要警惕信息差的存在 | 要警惕信息差 |
| 代词滥用 | 这三条建议有道理，我们不妨考虑它们 | 这三条建议有道理，不妨考虑 |
| 「和」包办 | 昂贵和不切实际 | 昂贵而不切实际 |
| 「当……的时候」 | 当他回到家里的时候，他放了心 | 他回到家里，看见枪还在，就放心了 |
| 被动滥用 | 被委派了……的任务 | 接到任务 |
| 抽象名词化 | 具备较高的可行性 | 可行性较高 |
| 无意义的「能够」 | 效率能够得到明显提升 | 效率会明显提升 |
| 「关于……的问题」 | 关于他有没有罪的问题，谁也不敢判断 | 他有没有罪，谁也不敢判断 |
| 介词堆叠 | 关于对这个问题的讨论 | 讨论这个问题 |

判断办法：这句话如果必须先想一遍英文才写得出来，就是欧化句。

## 九、标点（只列会影响语序判断的）

依据 GB/T 15834-2011《标点符号用法》，现行，2012-06-01 实施，2016 年复审继续有效。

- 顿号只连并列词语；并列的是分句，用逗号。「苹果、梨、桃」对，「他来了、她走了」错。
- 分号只用在已经含逗号的分句之间。
- 中文正文用全角标点；引号内是完整句子，句号放引号里。
- 不堆叠感叹号和问号。

## 十、发出去之前自检六步

1. **找主谓。** 每句能不能一句话说出「谁 做什么」。说不出，句子结构坏了。
2. **数「的」。** 一句三个以上，拆。
3. **量距离。** 修饰语离中心语隔了几个词，超过四五个就挪近或拆句。
4. **查关联词。** 主语同不同，位置对不对。
5. **出声读。** 读着要换气的地方，就是该加逗号或断句的地方；读完一遍找不到重点，语序有问题。
6. **删后半句。** 每句逗号后面那半删掉，前句还成立吗？不成立，就是一个观点拆成了两句。

## 十二、关于「让它学习标准汉语资料」

改不了权重。提示层能做的是三件事，别混为一谈：

1. **写进准则。** 每次会话开头读到，就是本轮的约束。这是提示层，不是训练层。
2. **配正误对照。** 上面各节的表格就是。模型按「错→对」的格式改写，比读一篇规范文章有效。
3. **查证而不猜。** 不确定某个搭配是否常用，去 BCC 查频次，别凭感觉造。

真要做长文本对齐，取 100 句左右的规范文本（社论、教科书、公文）当示例，比「喂一堆语料」有用；但示例超过二十句，上下文里就只剩示例了。

## 十三、汇报与警告（场景速查）

干活的过程不用管这些，发出去的那段话要管。

**汇报三段，一段一句：**

1. **结论。** 做完了 / 没做成 / 卡在哪儿 / 要你定。
2. **依据。** 只列能改变判断的事实，最多三条，一条一行。
3. **下一步。** 你要做什么，或者我接着做什么。没有第三步就只写两段，不为凑格式补一句「有问题随时找我」。

**警告两段：**

1. **会出什么事，什么时候出。** 第一句就说，不铺垫背景。
2. **现在处理还是先放着。** 给一个可选的处置，别只提示风险。

细则：

- 只写这一轮新查到的东西。试错的路径、失败的命令、走过的弯路，不影响判断就不写。
- 数字、文件名、路径照抄原样，不模糊成「大约」「相关文件」。
- 风险超过两条时只挑最紧的一条，其余等做完再说。
- 同一段里「另外」「顺便」「还有一点」各最多出现一次。
- 汇报里不评价自己的工作，不写「顺利完成」「效果不错」。
- 警告里不用「建议考虑」「可能需要留意」这类软收尾，直接说处理还是不处理。

**不传染（对我自己的约束）：**

- 不复述你说过的话，不把你的一句改写成三句。
- 不给你的表达打分，不说「这个问得好」「说到点子上了」。
- 不模仿你的语气、断句、口头习惯。
- 你说啰嗦就停，不解释为什么写长了。
